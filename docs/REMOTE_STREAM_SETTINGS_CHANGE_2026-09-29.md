# 远程串流设置变更说明（相对 b6f5942）

## 使用方式

在设置页开启“启用远程串流设置”后，可以分别指定远程分辨率、帧率和码率上限。每一项都可以选择“跟随全局”；码率还可以选择“自动推荐”或手动设置。未开启时，沿用原有全局配置。

## 与上一次提交相比

| 项目 | b6f5942 | 本次变更 |
| --- | --- | --- |
| 视频设置 | 一套全局分辨率、帧率和码率 | 增加仅用于互联网或 VPN 串流的逐项覆盖设置 |
| 连接路径 | 带宽探测自行识别路径 | 会话启动时识别一次路径，并将结果复用于带宽探测 |
| 启动配置 | 全局配置直接用于启动主机应用和 native 串流 | 解析目标地址后应用远程覆盖，再用于带宽策略、主机启动和 native 串流 |
| 显示与刷新率 | 启动前按全局设置请求刷新率和窗口尺寸 | 启动后按实际生效的远程帧率和尺寸更新请求；若主机在启动期间上报新尺寸，则保留主机尺寸 |

## 生效规则

- 路径识别为 WAN 或 VPN，且远程设置开关打开时才应用覆盖；LAN 和未识别路径使用全局配置。
- 分辨率与帧率可以单独继承全局设置。远程分辨率继续使用全局的主机缩放和反转设置。
- 远程码率设为“跟随全局”时沿用全局码率；设为“自动推荐”时按最终分辨率和帧率计算；手动值作为开流前测速及串流中自动调节的上限。
- 覆盖只修改当前会话的配置，不写回全局设置。存储值无效时跳过对应覆盖。

## 验证与边界

- `npm run check` 和 `git diff --check` 通过。
- 启动期间主机分辨率上报的时序保护只影响显示尺寸同步。
