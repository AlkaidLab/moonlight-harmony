## [1.0.0.780] - 2026-06-26
HDR 元数据、AV1 硬解与显示体验修复

### 新增
- **手动 HDR 亮度校准**：设置中可覆盖上报给 Sunshine 的 HDR 峰值亮度，HDR 画面发灰或偏暗时可手动校准，重新连接串流后生效。

### 修复
- **HDR 静态元数据透传**：串流时优先使用 Sunshine 服务端下发的 HDR10 静态元数据，缺失或非法时再回退到默认 BT.2020 元数据，减少亮度和色彩映射偏差。
- **AV1 硬解能力判断**：AV1 仅在系统报告硬件解码器可用时启用，并按具体硬件解码器名称创建实例，避免静默落到软解路径。
- **HDR 回调稳定性**：修复 HDR 模式回调签名不匹配导致元数据无法正确传递的问题，并补充元数据范围校验。
- **首页刷新按钮**：将「扫描网络」改为刷新已知主机状态，避免手动操作误停后台 mDNS 自动发现；按钮图标、禁用态和提示文案同步更新。
- **浮窗/PiP 尺寸**：改用实际测量到的视口尺寸计算画面布局，减少浮窗或小窗模式下的比例异常。
- **主机在线提示**：细化主机在线状态过渡提示，减少状态变化时的误导性反馈。

## [1.0.0.779] - 2026-06-23
串流启动与浮窗显示修复

### 修复
- **串流启动卡顿**：将连接启动流程移出 UI 线程，降低开始串流时页面无响应或卡住的概率。
- **浮窗画面裁剪**：窗口/浮窗模式改用实际窗口内容区计算串流画面尺寸，横屏浮窗下画面不再像被放大裁切。
- **缩放触控偏移**：旋转、分辨率变化和浮窗尺寸变化后同步缩放父容器尺寸，修复缩放状态下触控坐标偏移。

## [1.0.0.775] - 2026-06-14
开发者模式解锁与手动添加主机稳定性优化

### 新增
- **GitHub Star 开发者模式解锁**：设置中新增可选的 GitHub OAuth Device Flow 验证，确认账号已 Star 项目后可激活开发者模式；原有激活码方式继续保留作为兜底。

### 优化
- **HTTPS/FRP 端口探测更稳**：HTTPS serverinfo、端口懒解析和 FRP 推断重试统一沿用请求连接超时，减少自定义端口或端口转发场景下的误失败。
- **开发者验证隐私说明补充**：隐私政策和应用内说明补充 GitHub Star 验证涉及的本地状态、GitHub OAuth 与 GitHub API 调用范围。

### 修复
- **手动添加主机偶发 timeout**：手动输入主机时 `/serverinfo` 探测遇到瞬时超时会快速重试一次，并让在线主机使用更贴近 Android 的连接超时策略，减少“Android 可连但本客户端添加失败”的情况。

### 移除
- **停止跟踪本地开发者工具**：从仓库移除开发者激活码生成器和 HTML 算号器，仅保留本地 ignored 文件，避免敏感开发工具继续随仓库分发。

## [1.0.0.772] - 2026-05-18
外网域名连接修复 + 双触控板手柄支持 + 核心库同步

### 修复
- **外网 AAAA-only 域名连接超时**：用户反馈"手输 IPv6 字面量可连，绑了 IPv6 的域名超时"。推断鸿蒙底层 DNS 对仅 AAAA 记录的域名解析行为不稳定。修复方案：在 ETS 层主动用 `connection.getAddressesByName` 解析出 IPv6 字面量并持久化，后续轮询时并行竞速直接走 IPv6 直连；首次添加电脑失败时也会自动回退。

### 新增
- **双触控板手柄识别**（核心库）：支持带双触控板的控制器（如 DualSense Edge 等设备的扩展触控）。

### 优化
- **同步上游核心库**：合并 moonlight-common-c 上游修复与改进。
- **解码队列深度语义统一**：设置项从“解码器缓冲区”明确为“解码队列深度”；自动档固定等于 2，始终用于解码器缓冲请求，并在同步解码模式下同时约束软件待解码队列，避免“界面显示自动、实际行为分叉”的歧义。

### 移除
- **HighQuality 环绕声 LFE 声道重排**：回滚此前的实验性修改，避免在某些 7.1 配置下产生异常声道映射。

## [1.0.0.771] - 2026-05-14
连接体验优化：首帧对齐 + RTSP 瞬态重试 + 连接中提示

### 优化
- **连接中 → 首帧动画过渡**：原本加载遮罩在解码器启动的那一刻就瞬间消失，会露出尚未填充画面的黑底 → 现在推迟到"首帧真正解码完成"才切换，且遮罩以 320ms 淡出+轻微放大的形式退场，与首帧出现严丝合缝。
- **连接中遮罩重做**：使用当前应用的海报作为背景（模糊 + 渐变暗化），填充等待 launchApp / 首帧的几秒钟，不再是纯黑屏。从电脑卡片直接串流时，回退到 PcView 的全局壁纸作为兜底背景。
- **连接中随机小课堂提示**：随机展示一条隐藏手势 / 手柄快捷键 / 隐藏能力提示，让等待时间有趣且可能学到新东西。

### 修复
- **RTSP 握手瞬态错误自动重试**：偏远程/弱网场景下 ANNOUNCE 阶段偶发 errno 4/32/104/110（底层 socket 被中断或超时）导致“错误码 4”，现在会自动重试一次，用户无感。
