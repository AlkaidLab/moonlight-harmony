## [1.0.0.735] - 2025-07-18
编辑体验优化 + 首页扫码导入 + 手柄功能补齐 🎮

### 新增
- 📱 首页标题栏新增扫码导入按键配置入口，无需进入编辑模式即可导入
- 📤 系统分享面板 — 支持将按键配置分享到好友/其他应用
- 📐 PPT 风格元素对齐吸附 — 拖拽时智能吸附对齐参考线，替代网格吸附
- 🎮 手柄触摸板作为鼠标功能 (DualSense/DualShock4 via USB)
- ⚙️ 补齐虚拟手柄与高级设置项的实际功能（引导按钮、仅L3R3、振动反馈、竖屏半高、禁用警告）
- 🔧 ESC 菜单按键可替换 — 支持 ESC/F1/F12/~ 四种配置

### 修复
- 🩹 自定义按键触摸事件穿透到游戏流的问题
- 🔧 DS4 摇杆 Y 轴双重取反 bug
- 🛠️ USB 驱动 DDK 模式 stop() 流程整理

### 移除
- 🗑️ 清理不可实现的设置项 (REDUCE_REFRESH_RATE) 和死代码

## [1.0.0.734] - 2025-07-17
自定义按键系统全面升级，二维码分享配置 📱

### 新增
- 🎮 自定义按键核心系统 — 支持14种操作类型、预设模板、完整编辑功能
- 🕹️ 新增控件：方向键(VirtualDPad)、径向菜单(WheelPad)、透明摇杆/方向键
- 📱 二维码分享配置 — v2紧凑编码压缩70-90%，支持扫码/剪贴板导入导出
- ↩️ 撤销/重做功能 — 系统图标，编辑操作可追溯
- 📐 线宽自定义 — 按键边框粗细可调(0-6)

### 优化
- 🎯 虚拟控制器触摸处理重构，响应更精准
- 🔧 网络层 NvHttp 错误处理改进
- 🎨 编辑模式工具栏布局优化，撤销/重做移至右侧
